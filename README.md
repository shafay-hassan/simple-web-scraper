# Simple Web Scraper

This is a web scraper to scrape data from website. It clearly keeps them organised in a strutured format and provide it in a structured format.

## Requirements:
    – Python 3
    – beautifulsoup4
    – requests
    – lxml
    
 ## Installation:
     To install these requirements go to the terminal and use pip install and their names.
     
 ## Usage:
      To run this script simply just edit the places where you want to add your own website of choice and the data you want to scrape.
      
  ## Output:
       Running it will then provide you the exact data from the website upfront in a structured format.
